## 一、结论速览

| 维度 | 结论 |
|---|---|
| **核心链路（RAGFlow→qa_service→Ollama）** | 能跑，接口可用；但**引用强制与拒答判定两个核心契约未真正落地**（HIGH） |
| **部署（Docker/K8s）** | Docker 镜像可构建；**K8s 清单有 1 个 BLOCKER（args 覆盖 CMD → 必 CrashLoop）** |
| **监控/告警** | 指标链路可信（6 指标名/单位/查询全部对齐，3 target up，10 条 PromQL 实测有数据）；**告警链路不完全可信**（无数据被当 0、无去抖、状态仅内存、无外部 watchdog） |
| **脚本** | **2 个 BLOCKER：PowerShell 脚本丢 BOM 后 PS5.1 无法执行**；此外多处"配置/评测假成功"（不判状态、不校验回读） |
| **微调** | 脚本结构在 5.x 下可运行，但 **train-serve skew 严重 + 评测集污染**，作为"微调方案"不可交付 |
| **评测证据链** | 原始逐题数据被一次 `--limit 1` 试跑覆盖（仅剩 1 条），89.8% 当前**不可追溯**；需重跑 |
| **文档一致性** | 多处数字/表述互相矛盾（见第五节） |

**总体：本机演示可用；作为对外/生产/K8s 交付不可用。**
